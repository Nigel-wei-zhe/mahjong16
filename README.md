# 今夜有局｜台灣十六張麻將

走進霓虹夜街，和她們同桌打牌，也能開個包廂，邀朋友一起來一局。

**[立即遊玩](https://mahjong.nigel-lee.com/)**

## 遊戲特色

- **單機練習**：隨時和三位電腦牌搭子對局。
- **好友包廂**：分享房號或邀請連結，最多四人一起打，空位由電腦補上。
- **八位角色**：瑟琳、蕾歐、薇拉、蜜雅、凜、白音、艾莉絲、露娜，各有個性、牌風與專屬語音。
- **霓虹牌桌**：3D 麻將牌、角色立繪與吃碰槓胡演出，陪你打到下一圈。
- **自由開局**：一圈或一將，自選底台與出牌時間；內附規則說明與台數表。

## 怎麼玩

直接用瀏覽器開啟，免安裝。手機建議橫向遊玩。

選「練習」即可和電腦對局；選「包廂」則可開房或加入朋友的牌局。點一下選牌，再點一下打出，也可以按住往上滑出牌。
